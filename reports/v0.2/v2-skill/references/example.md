# 虚构示例：只保留有效状态

输入：U1要求中文、三章、含编程、交付PDF。U2改为去掉编程、交付Markdown，其他要求保留。助手建议十页彩色PDF但未获接受，且声称已完成但没有文件证据。

合适的记录：

```markdown
# 入门指南 | v1
目标：制作新手指南。来源：本轮U1—U2；U数字=用户消息。
要求：R1 中文；R2 三章 [U1]；R3 不含编程；R4 交付Markdown，不要PDF [U2]。
状态：助手声称已完成，未提供产物，尚未核实。
下一步：如有成稿先核对，否则起草。未授权发布。
```

PDF和编程已被替换，不在别的栏目再次当作有效方案；未确认的海报建议不保存。不能仅记录“按U2改”，因为新会话可能没有U2原文。
