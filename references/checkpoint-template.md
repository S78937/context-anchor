# 紧凑检查点模板

每条事实只出现一次；空栏目删除。任务名及来源可用短标记，短标记必须能解释。无已知日期可省略，不猜测。

```markdown
# 任务名 | v1
目标：一句话交付目标（不重复下面条件）。
来源：当前可见材料范围；U数字=对应用户消息。

要求：
- R1 …；R2 … [U1]
- R3 条件成立时…，否则… [U18]

状态：已完成事项+可查证据；声称完成但未核实的事项。
下一步：动作；阻塞/权限边界（仅有时写）。
```

更新时沿用现有ID，修改条目的内容和来源；删除的要求可标废止，勿把同一ID改派到无关要求。复杂任务有多条约束就展开要求列表，不强行塞进一段。保留禁止事项、精确值、逐字要求和条件分支。

不要求为了每个字段填“无”。恢复下一步需要的事实应直接保留，不能只留一个失效文件路径。
