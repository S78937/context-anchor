# 接续记录模板

复制以下结构，按实际信息填写；无信息写“未知”或“无”。示例占位文字应替换，不要据此编造日期或测试结果。

```markdown
# 任务：简短任务名
- 任务 ID：
- 版本：1（每次实际保存递增）
- 更新日期：实际已知日期；无法确定写未知
- 范围：属于哪个项目，以及本次要交付什么
- 来源范围：本轮可见聊天/用户提供的记录/实际读取的文件

## 目标与验收
- 目标：
- 用户认定完成的条件：

## 当前有效要求
| ID | 要求 | 来源 | 状态 |
| --- | --- | --- | --- |
| R1 | 用户明确要求 | 原话短摘或可访问来源 | 生效 |

## 决定与修正
- 已确认决定及依据：
- 被替代决定 → 新决定（谁作出修正、来源）：
- 助手建议或假设（尚未获用户确认）：

## 当前进度与证据
- 已完成：结果 + 文件/实际工具返回等证据
- 仅记录声称完成、尚待核实：
- 正在进行：
- 未完成或阻塞：

## 相关材料
- 当前任务需要的文件位置和用途（不复制秘密内容）：

## 下一步
- 下一项可执行动作：
- 尚待澄清且影响执行的问题：
- 已明确的操作范围/发布边界：
```

新聊天入口示例：
“请使用 context-anchor，读取我提供的接续记录，核对当前目标和有效要求，再继续下一步。如果材料缺失，请明确指出。”
