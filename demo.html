AI 会忘事，所以我给它写了张纸条

长对话换个窗口、隔天接着干的时候，AI 会把你早就说过的事忘掉。下面这段是实拍：第一幕它忘干净， 第二幕和第三幕用的是同一个仓库里的接续记录（references/example.md 里的虚构例子）。

02接续记录

（播放到第二幕，这里会显示 Context Anchor 生成的那份文件）

格式抄自 references/checkpoint-template.md，内容是 references/example.md 里的虚构例子。

这东西存下来就是一个普通文件。没有后台服务，没有 API 调用，不上报任何数据。 下次新开对话把它贴过去，AI 就能对着它一条条核对，不用再猜。

v0.2 用了两段各 211 条消息、合计 31,455 字符的虚构长对话，三组各跑一次， 新会话只凭那份记录恢复成稿。

说清楚：三组都 48/48，说明这轮没测出 v0.2 比普通提示更准——三条都撞天花板了。 唯一测出来的差别是记录短了 52.1%。样本小，评分是我自己打的，没做盲审， 也没在 OpenClaw 原生环境装过。这些都写在仓库的 TEST_RESULTS.md 里。

04怎么用

  1. 下载 v0.2 Release，把 context-anchor 文件夹放进 ~/.codex/skills/ 或 ~/.openclaw/skills/
  2. 当前对话里说：「使用 context-anchor：把当前任务的目标、硬性要求、我后来的修正和未完成事项整理成接续记录」
  3. 开一个新对话，把记录发过去，说：「使用 context-anchor：读取这份接续记录，核对仍有效的要求，接着完成下一步」
